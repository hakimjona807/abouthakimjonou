# Hakimjon | Shaxsiy Portfolio Sayti (Personal Portfolio Website)

13 yoshli IT va ingliz tili o'rganuvchisi Hakimjon uchun yaratilgan zamonaviy, futuristik portfolio veb-sayti.

---

## 🚀 Vercel yoki GitHub Pages ga yuklash (Deploy qilish)

### 1-usul: Vercel orqali chiqarish (Eng tez va osoni)
1. Kodlarni GitHub-ga yuklang (`git push`).
2. [Vercel.com](https://vercel.com) saytiga kiring va GitHub repozitoriyangizni (`abouthakimjonou`) import qiling.
3. Loyihada `.npmrc` va `vercel.json` fayllari allaqachon tayyorlangan, shuning uchun hech qanday xatoliksiz bir necha soniyada saytingiz ishga tushadi!

---

### 2-usul: Avtomatik GitHub Pages
1. Ushbu loyihani o'zingizning GitHub hisobingizga yuklang (push qiling).
2. GitHub da repozitoriyingizga kiring:
   - **Settings** (Sozlamalar) bo'limiga o'ting.
   - Chap tomondagi menyudan **Pages** bo'limini tanlang.
   - **Build and deployment** bo'limida **Source** ni **GitHub Actions** ga o'zgartiring.
3. Loyihada tayyor `.github/workflows/deploy.yml` fayli borligi sababli, har safar kod yuklaganingizda sayt avtomatik ravishda internetda ishga tushadi!

---

### 2-usul: Kompyuterda ishga tushirish (Local Run)

1. Kerakli paketlarni o'rnating:
   ```bash
   npm install
   ```

2. Dasturchi rejimida ishga tushiring:
   ```bash
   npm run dev
   ```
   Brauzerda `http://localhost:3000` manzilini oching.

3. Saytni yig'ish (Build qilish):
   ```bash
   npm run build
   ```
   Tayyor fayllar `dist/` papkasida hosil bo'ladi.
